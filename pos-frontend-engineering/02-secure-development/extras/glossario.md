# Glossário - Secure Development

| Termo | Definição resumida |
|---|---|
| API Gateway | Ponto de entrada para APIs, aplicando políticas como autenticação, autorização, rate limit e monitoramento. |
| BOLA | Broken Object Level Authorization; falha que permite acessar objeto de outro usuário manipulando ID. |
| Broken Authentication | Falhas em autenticação que permitem assumir identidade, comprometer tokens ou abusar de senhas fracas. |
| CORS | Mecanismo de navegador que controla quais origens podem acessar recursos de outra origem. |
| CVE | Identificador padronizado para vulnerabilidades conhecidas. |
| CWE | Classificação de fraquezas de software que podem causar vulnerabilidades. |
| DevSecOps | Integração de segurança ao desenvolvimento e operações. |
| Identity Provider | Serviço de gestão de identidade, autenticação, MFA e emissão de tokens. |
| JWT | Formato de token usado para transportar claims, exigindo validação de assinatura, expiração, emissor e audiência. |
| MASVS | Padrão OWASP para verificação de segurança de aplicativos móveis. |
| mTLS | TLS mútuo, em que cliente e servidor se autenticam mutuamente. |
| OAuth 2.0 | Protocolo de autorização para delegar acesso com tokens. |
| OpenID Connect | Camada de identidade sobre OAuth 2.0 para autenticação. |
| RASP | Runtime Application Self-Protection; proteção da aplicação em tempo de execução. |
| Rate Limiting | Limitação de requisições por período para evitar abuso. |
| SAML | Protocolo XML usado em SSO corporativo. |
| SAST | Análise estática de segurança do código fonte. |
| SCA | Análise de composição de software para dependências e bibliotecas. |
| SIEM | Plataforma de coleta, correlação e análise de eventos de segurança. |
| SOAR | Plataforma de orquestração e automação de resposta a incidentes. |
| Tampering | Manipulação não autorizada de dados, payloads, código ou comportamento. |
| WAF | Firewall de aplicação web. |
| XSS | Cross-Site Scripting; execução de script malicioso no navegador. |
