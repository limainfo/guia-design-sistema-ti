# 05 - Glossário

| Termo | Definição curta |
|---|---|
| API | Interface de programação que permite comunicação entre softwares |
| API First | Abordagem em que o contrato da API é definido antes do código |
| API Gateway | Ponto único de entrada que aplica políticas e roteia chamadas |
| API Key | Chave/token usado para identificar consumidor de API |
| API Portal | Portal de documentação, onboarding, suporte e consumo de APIs |
| API Product Manager | Papel responsável por estratégia, backlog e KPIs da API |
| AMQP | Protocolo de mensageria com broker, filas e roteamento |
| Authorization Server | Servidor que emite tokens no OAuth2 |
| Avro | Formato binário com schema, comum em integração de dados |
| Batch | Processamento em lote |
| BOLA | Broken Object Level Authorization; acesso indevido a objeto |
| BOPLA | Broken Object Property Level Authorization; acesso indevido a propriedade |
| Broker | Intermediário que recebe e distribui mensagens/eventos |
| Cache | Cópia temporária de dados para reduzir latência e carga |
| CDN | Rede de distribuição de conteúdo próxima ao usuário |
| Client Credentials | Fluxo OAuth2 para comunicação sistema-sistema |
| Content Negotiation | Negociação de formato por headers como Accept e Content-Type |
| Content-Type | Header que informa formato do corpo enviado |
| EDA | Event-Driven Architecture; arquitetura orientada a eventos |
| ETag | Identificador de versão de recurso usado em cache |
| Event Sourcing | Persistência do estado como sequência de eventos imutáveis |
| GraphQL | Linguagem de consulta para APIs em que cliente escolhe campos |
| gRPC | RPC moderno baseado em HTTP/2 e Protobuf |
| HATEOAS | Hypermedia as the Engine of Application State; links de ações na resposta |
| HTTP | Protocolo de aplicação usado na Web |
| HTTPS | HTTP protegido por TLS |
| IaaS | Infraestrutura como Serviço |
| IAM | Identity and Access Management; controle de identidade e permissão na nuvem |
| Idempotência | Repetir a mesma operação gera o mesmo resultado final |
| JWT | JSON Web Token; token com header, payload e assinatura |
| Lambda | Serviço serverless da AWS para execução sob demanda |
| Matrix Variable | Forma de enviar parâmetros no path, menos comum |
| Message Queue | Fila em que cada mensagem é entregue a um consumidor |
| MQTT | Protocolo leve de mensageria, comum em IoT |
| OAuth2 | Protocolo de autorização delegada baseado em tokens |
| Offset | Posição de leitura em um log de streaming |
| OpenAPI | Especificação para descrever APIs HTTP |
| PaaS | Plataforma como Serviço |
| Parquet | Formato binário colunar usado em Big Data |
| Path Variable | Valor embutido no caminho da URL |
| PKCE | Extensão de segurança para Authorization Code em clientes públicos |
| Polling | Cliente consulta repetidamente para verificar atualização |
| Protobuf | Protocol Buffers; serialização binária usada em gRPC |
| Pub/Sub | Padrão em que assinantes recebem cópia de eventos de um tópico |
| Query Param | Parâmetro enviado na query string da URL |
| Rate Limit | Limite de chamadas por consumidor em uma janela de tempo |
| REST | Estilo arquitetural baseado em recursos, HTTP e representações |
| RESTful | API que aplica princípios REST |
| Resource Server | API que protege e entrega recursos no OAuth2 |
| Saga | Padrão para transações distribuídas longas |
| SaaS | Software como Serviço |
| Scope | Permissão concedida a um token OAuth2 |
| SOAP | Protocolo de mensagens XML com envelope e WSDL |
| SSRF | Server-Side Request Forgery; servidor acessa URL manipulada pelo atacante |
| Stateful | Servidor mantém estado/sessão |
| Stateless | Servidor não mantém estado entre requisições |
| Streaming | Processamento contínuo de eventos em log |
| TLS | Protocolo de segurança que protege o canal HTTPS |
| URI | Identificador de recurso; conceito mais amplo que URL |
| URL | Localizador de recurso com esquema, host e path |
| WebHook | Chamada HTTP disparada por evento para uma URL do consumidor |
| WebSocket | Canal persistente full duplex entre cliente e servidor |
| WSDL | Contrato XML de serviços SOAP |
| WS-* | Família de extensões SOAP, como WS-Security e WS-Transaction |
